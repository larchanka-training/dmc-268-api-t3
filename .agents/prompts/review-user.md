# Шаблон пользовательского сообщения для AI-ревью

Системное сообщение: содержимое `review-system.md`. JSON Schema передаётся отдельно через поддерживаемый формат SDK либо включается доверенным оркестратором. Не склеивайте описание PR с системными инструкциями.

Доверенный оркестратор подставляет объект (пример полей, не готовый API):

```json
{
  "run_id": "run-from-database",
  "base_sha": "full-base-sha",
  "head_sha": "full-head-sha",
  "input_complete": true,
  "anchors": [{"path": "example.py", "side": "RIGHT", "line": 7}]
}
```

Задача: проанализировать предоставленный diff и относящийся к нему контекст по схеме review/1.0.0. Затем передать недоверенные артефакты отдельным JSON-полем `untrusted_artifacts` с типом (diff/file/PR-description), точным SHA и содержимым. Сериализовать стандартным JSON encoder; разделители сами по себе не защищают от prompt injection. Ограничить объём до вызова модели и пометить input_complete=false при усечении.

Файлы всегда читать по фиксированному SHA. Исключённые/binary/недоступные файлы явно перечислить в контексте. Модель не формирует доверенный список anchors. После ответа приложение выполняет schema + semantic validation; невалидный ответ не сохранять как успешный отчёт. Ограниченный repair-запрос допустим только в общем бюджете; исчерпание даёт ошибку.
